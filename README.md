# Pulse Mobile

The mobile app for Pulse, built with Expo and React Native.

## Setup

```bash
npm install
npm start
```

Then press `i` to open the iOS simulator, `a` for Android, or `w` for web.

## Commands

```bash
npm run ios
npm run android
npm run web
```

## Stack

- Expo
- React Native
- TypeScript
- React Navigation
- Redux Toolkit

## Project Structure

```text
src/
  components/   Reusable UI components
  features/     Feature state and logic
  navigation/   App navigation
  screens/      App screens
  services/     API and storage services
```
